vhtml! Macro Demo

Maud-like syntax compiled to velo_ast nodes. Every syntax sugar from commits 9e8b176 (vhtml macro) and ec916e1 (schema + keyed @for) is shown here.

Live demo

The #[wasm_bindgen(start)] entry point mounts all_features_view() into <body>. Click the increment / toggle buttons — the DOM updates surgically (fine-grained reactivity), no page reload.

Build & serve with Trunk: 

trunk serve --dir examples/vhtml-demo

Then open http://localhost:8080.
